# 泰语学习（手机 PWA 应用）

方案见 `方案.md`。当前已完成第 1–3 期的主体功能，词库 137 词（6 个分类），全部为起草稿，待懂泰语的人校对。

## 已有功能
- 今日页：每日新词、进度环、连续打卡、等级
- 分类页：全部分类直接可学（无解锁限制）、进度环、词表
- 学习卡：泰文、罗马音、声调曲线、逐音节声调规则（辅音类／活死音节／声调符号，由 tools/声调规则.py 自动推导）、中文、分词着色例句、发音；没记住／记得／太简单
- 复习：间隔重复（1/3/7/14/30 天）
- 自动连读：每词泰语 N 遍＋中文，陌生／不熟悉／熟悉／精通
- 陪睡模式：时长、分类、随机顺序，静音垫片保持锁屏播放
- 声调规则速查表（设置页或学习卡进入）
- 发音语速：0.5／0.8／1／1.2／1.5 倍，默认 1，设置页和学习卡右上角可切换，对单词、例句、连读、陪睡都生效
- 设置：每日词数、连读遍数、导出／导入进度

## 文件夹
```
docs/    网页应用（index.html、app.js、style.css、sw.js、audio/、data/words.json）
data/   源词库.txt（编辑词库只改这个文件）
tools/  生成词库.py、生成音频.py
```

## 本机预览
```bash
python -m http.server 8765 --directory docs
```
浏览器打开 http://localhost:8765 。

## 改词库后
```bash
python tools/生成词库.py
```
```bash
PYTHONUTF8=1 python tools/生成音频.py
```
新词追加到分类末尾，不要改已有词的泰文（编号由泰文生成，改了会丢该词进度）。

## 装到手机
需要一个 HTTPS 网址（离线缓存和"添加到主屏幕"都要求）。部署位置待定，见 `方案.md` 第六节。部署后用 iPhone Safari 打开网址 → 分享 → 添加到主屏幕。

## 说明
- 进度存在手机浏览器本地，换手机前先在设置里导出。
- 音频由 edge-tts（微软在线语音，非官方接口）生成；若要正式长期使用，可改用 Azure TTS 官方接口。
